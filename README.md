# MAYA LABS Website

A responsive single-page website for MAYA LABS focused on defense, aerospace, UAV/UGV, drone defense, AI/ML, robotics, cybersecurity and deep-tech R&D.

## Files

- `index.html` — complete website content and structure
- `assets/css/style.css` — responsive visual design
- `assets/js/main.js` — navigation, smooth scrolling and reveal animations

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Deployment

Upload the complete folder to your hosting provider and point `www.mayalabs.in` to the deployed site.
